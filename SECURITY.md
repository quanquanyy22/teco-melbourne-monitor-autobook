# Security Policy

## Supported Versions

This project currently has no formal release versions. Security fixes are considered for the latest `main` branch only.

| Version | Supported |
| ------- | --------- |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through GitHub's private vulnerability reporting feature, if enabled. Do not open a public issue containing exploit details, personal data, notification topics, prefilled URLs, logs, screenshots, or browser state.

This is a personal project, so there is no guaranteed response time. Reports will be reviewed when practical. If a report is accepted, I will work toward a fix where feasible; if it is declined, I may explain the reason.

If private vulnerability reporting is unavailable, open a public issue containing only a request for a private contact method—do not disclose the vulnerability details publicly.
